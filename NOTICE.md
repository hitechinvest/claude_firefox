# Правовая заметка

## Что лежит в этом репозитории

Только код порта: `port.py`, `ff-shim/`, `ff-content/`, `tools/`. Он написан
с нуля для этого проекта.

## Чего здесь нет

Исходников расширения «Claude» для Chrome. Это проприетарный продукт Anthropic,
и его код сюда не копируется. `port.py` скачивает расширение из Chrome Web Store
на машину сборки, патчит его локально и складывает результат в `build/`, который
исключён через `.gitignore`.

Практическое следствие: собранный `build/` содержит код Anthropic. Он для
личного использования — не выкладывайте его в публичный доступ, не публикуйте
на addons.mozilla.org и не распространяйте иным образом. Условия Chrome Web
Store и лицензия Anthropic такого не разрешают.

## Статус

Порт неофициальный. Он не связан с Anthropic, не поддерживается ей и не
одобрен. «Claude» и «Anthropic» — товарные знаки Anthropic PBC; здесь они
используются только для указания на то, что портируется.

Расширение по-прежнему требует действующей учётной записи Claude с
подходящим тарифом. Порт не обходит никаких ограничений: ни лицензионных,
ни серверных, ни платных.

## Обратная разработка

Порт не вскрывает и не изменяет логику расширения. Он подменяет только те
браузерные API, которых нет в Firefox, — ровно то, что нужно для
совместимости. Внутренние алгоритмы, протоколы и сетевые вызовы Anthropic
остаются как есть.
