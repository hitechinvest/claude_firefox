# Tab Share — расшаривание вкладки Firefox через ваш сайт

Расширение для Firefox, которое **транслирует выбранную вкладку через PHP-скрипт
на вашем сайте**. Другой пользователь открывает в браузере `viewer.php` на том же
сайте, вводит PIN — и видит вкладку в реальном времени, может кликать, скроллить,
печатать, переходить по ссылкам и по адресу, жать «назад»/«вперёд»/«обновить».

Всё идёт через один PHP-скрипт (`relay.php`) — точка встречи это ваш сервер,
поэтому ни проброс портов, ни белый IP, ни установка чего-либо у гостя не нужны.

Это самостоятельный проект в папке `tab-share/`, он не связан с портом Claude
в корне репозитория.

## Как это устроено

Расширения Firefox не умеют слушать TCP-порт (в WebExtensions нет серверных
сокетов), поэтому «встречаются» обе стороны на вашем сайте:

```
   вкладка          расширение Firefox            ВАШ САЙТ (PHP)              гость
   ┌────┐           ┌───────────────┐   HTTPS     ┌──────────────┐   HTTPS   ┌──────────┐
   │ …  │◄─────────►│ captureTab →  │  POST кадр  │              │  GET кадр │ viewer.php│
   └────┘  синтет.  │  кадры        ├────────────►│  relay.php   │◄─────────►│ (браузер)│
           ввод     │ ввод ← pull   │◄────────────┤  + ./data    │ POST ввод └──────────┘
                    └───────────────┘  pull ввод  └──────────────┘
```

- **Расширение** снимает выбранную вкладку и POST-ит кадры на `relay.php`. Есть
  два режима: **JPEG** (скриншот вьюпорта через `tabs.captureTab`) и **HTML**
  (снимок DOM — передаётся сам код страницы, а не картинка). Ввод гостя оно
  забирает оттуда же коротким опросом (`pull`) и проигрывает в вкладке
  синтетическими событиями.
- **`relay.php`** — единственный скрипт, через который идёт всё. Он принимает
  кадры от расширения, отдаёт их гостям (long-poll), принимает ввод от гостей и
  копит его для расширения. Состояние — во временных файлах в `./data`.
- **`viewer.php`** — страница-зритель для гостя. Тянет кадры и шлёт ввод в тот
  же `relay.php`.

Никаких внешних библиотек: только PHP на сайте и Firefox с расширением.

## Установка

Нужны **Firefox 115+** и хостинг с **PHP 7.4+** (подойдёт обычный shared).

### 1. Загрузить PHP на сайт

Скопируйте `tab-share/server/relay.php` и `tab-share/server/viewer.php` в одну
папку на вашем сайте, например `https://ваш-сайт/tabshare/`. Папка `data`
рядом с `relay.php` создастся сама при первом запуске и должна быть доступна на
запись (обычно так и есть). В неё автоматически кладётся `.htaccess`, закрывающий
прямой доступ к кадрам из веба.

Проверка: откройте `https://ваш-сайт/tabshare/relay.php?action=meta&session=x` —
должен вернуться JSON с ошибкой `no such session` (значит, PHP работает).

### 2. Загрузить расширение в Firefox

`about:debugging#/runtime/this-firefox` → **Load Temporary Add-on** →
`tab-share/extension/manifest.json`. Временное расширение живёт до перезапуска
Firefox.

## Использование

1. Нажмите иконку **Tab Share**.
2. Выберите вкладку и впишите **URL релея**, например
   `https://ваш-сайт/tabshare/relay.php` (запомнится на будущее).
3. Выберите **что передавать** — картинку (JPEG) или HTML (см. ниже) — и при
   желании подправьте FPS (1–10) и качество JPEG (20–90).
4. **Начать трансляцию**. Появится ссылка на `viewer.php` и **PIN-код**.
5. Отправьте гостю ссылку и PIN (кнопка «Скопировать ссылку с PIN» даёт ссылку
   с уже вшитым PIN — гостю останется только открыть её).
6. Гость открывает ссылку, вводит PIN — и управляет вкладкой. Кнопкой
   «Управление: вкл/выкл» он может временно перестать передавать ввод.

Зрителей может быть несколько, каждому нужен PIN. Кнопка **Остановить** удаляет
сессию на сервере и рвёт доступ.

## Режимы: картинка (JPEG) или HTML (DOM)

**JPEG** — расширение шлёт скриншот видимой части вкладки, гость видит `<img>`.
Это точная копия экрана: работает всё, что рисуется, — `<canvas>`, `<video>`,
WebGL, картинки за авторизацией. Минус — трафик и «мыло» на тексте, видно только
вьюпорт (гость листает через хост).

**HTML** — расширение сериализует DOM (`document.documentElement.outerHTML` +
текущие значения полей + `<base href>` для относительных ссылок, без `<script>`)
и шлёт сам код. Гость рендерит его в изолированном `<iframe>` (`sandbox` без
`allow-scripts`, поверх — прозрачный слой для ввода, чтобы зеркало не перехватывало
клики и не уводило по ссылкам). Плюсы: чёткий текст, обычно меньше трафика, и
гость листает **весь документ локально**, без задержки. Минусы:

- `<canvas>`, `<video>`, WebGL, картинки/шрифты **за авторизацией** у гостя не
  отрисуются: подгрузки идут из его браузера напрямую с сайта-источника.
- JS-виджеты «замирают» между снимками (скрипты у гостя отключены намеренно).
- Каждый снимок — это перерисовка `<iframe>` целиком (без диффа), поэтому на
  тяжёлых страницах возможно мерцание; держите FPS низким (1–2).
- Координаты клика считаются от **всего документа**, а не от вьюпорта, поэтому
  расширение при необходимости само подкручивает прокрутку к цели.

Правило простое: **текстовые страницы и формы — HTML; карты, видео, канвасы и
всё «нарисованное» — JPEG.**

## Безопасность — прочитайте

Открытый доступ означает, что зритель управляет вкладкой **как вы сами**:
залогиненные сессии, почта, соцсети — всё доступно ему.

- **Ролевые секреты.** Расширение держит длинный `host_key` (только оно может
  слать кадры и забирать ввод). Гость знает лишь короткий **PIN**, и без него
  `relay.php` не отдаёт кадры и не принимает ввод. Чужой `host_key` не может
  перехватить активную сессию.
- **PIN короткий** — это защита от случайного захода, а не от целенаправленного
  подбора. `relay.php` не имеет встроенного бана по числу попыток; при
  публичном сайте разумно добавить лимит на уровне сервера (fail2ban, mod_evasive)
  или увеличить PIN.
- **HTTPS обязателен для интернета.** Ставьте `relay.php` только на сайт с TLS —
  иначе PIN и картинка идут открытым текстом. Расширение принимает и `http://`
  (для локального теста), но для внешнего доступа используйте `https://`.
- **Сессия видна в файлах на сервере.** `./data/<session>/` содержит последний
  кадр и очередь ввода, пока идёт трансляция; `stop` удаляет папку. `.htaccess`
  закрывает прямой доступ, но на всякий случай не держите на этом сайте лишнего.
- **Long-poll держит PHP-воркер.** Каждый активный зритель занимает один процесс
  PHP-FPM до ~10 секунд между кадрами. На дешёвом хостинге с малым числом
  воркеров держите зрителей немного.
- Держите доступ включённым ровно столько, сколько нужно, и жмите «Остановить».

## Что работает иначе (ограничения платформы)

Это границы WebExtensions, а не недоделки:

- **Синтетический ввод не доверенный** (`isTrusted === false`). Обычные сайты и
  React-приложения слушаются, но страницы, проверяющие `isTrusted`, кликов не
  увидят. До адресной строки, файловых диалогов и окон ОС ввод не достаёт —
  управляется только содержимое страницы.
- **В JPEG-режиме снимается только видимая часть** вкладки (`tabs.captureTab`
  берёт вьюпорт); в HTML-режиме гостю доступен весь документ.
- **Привилегированные страницы не снять и не поправить**: `about:*`,
  `addons.mozilla.org`, просмотр исходника. Кадр не снимется, будет ошибка.
- **Задержка и «мыло».** Это поток JPEG-скриншотов через ваш сервер, а не
  видеокодек, плюс сетевой путь до хостинга. Выше FPS — больше трафика и нагрузки
  на сайт; подбирайте FPS/качество под канал.
- **Навигация — через API вкладки** (надёжнее синтетики): адрес, назад, вперёд,
  обновить обрабатываются в фоне расширения.

## Тесты

```sh
cd tab-share/server
node test-relay.mjs      # нужен php в PATH и Node 18+
```

Тест (18 проверок) поднимает `php -S` во временной копии и проходит весь цикл:
создание сессии, отказ чужому `host_key`, заливку кадра, отклонение неверного
PIN, получение кадра гостем, передачу ввода и навигации, учёт зрителей, long-poll
с доставкой нового кадра, **HTML-кадр** (`Content-Type: text/html` + `X-Frame-Meta`
и doc-координатный ввод) и удаление сессии по `stop`.

> Встроенный `php -S` однопоточный, поэтому тест запускает его с
> `PHP_CLI_SERVER_WORKERS=6` — иначе long-poll заблокировал бы единственный
> воркер. На реальном хостинге с PHP-FPM запросы и так идут параллельно.

## Протокол `relay.php`

Все параметры — в query string; тело `frame` — сырой JPEG, тело `input` — JSON.

| Действие | Кто | Параметры / тело | Ответ |
| --- | --- | --- | --- |
| `start` | host | `session, host_key, pin` | `{ok, session}` |
| `frame` | host | `session, host_key[, meta]` + тело; `Content-Type` кадра | `{ok, ver, viewers}` |
| `pull` | host | `session, host_key` | `{ok, events[], viewers}` |
| `stop` | host | `session, host_key` | `{ok}` |
| `view` | guest | `session, pin, viewer, since` | тело кадра + `Content-Type` + `X-Frame-Ver` + `X-Frame-Meta`, либо 204 |
| `input` | guest | `session, pin, viewer` + тело=JSON `{t,payload}` | `{ok}` |
| `meta` | оба | `session` | `{ok, live, ver, viewers}` |

Тело `frame` — сырой JPEG (`Content-Type: image/jpeg`) или HTML
(`text/html`); для HTML в `meta` едет urlencoded JSON с размерами документа,
который `view` возвращает в заголовке `X-Frame-Meta`.

`t` в событии ввода — `input` (мышь/клавиатура) или `nav`
(`back`/`forward`/`reload`/`goto`). Координаты `x,y` нормализованы [0..1]:
относительно вьюпорта (JPEG) или всего документа при `doc:true` (HTML).

## Структура

```
tab-share/
  extension/
    manifest.json         MV2, id tab-share@local, права tabs/<all_urls>/storage
    background.js          съём вкладки (JPEG/HTML), POST кадров, pull ввода, навигация
    content-input.js       проигрывание ввода + снимок DOM для HTML-режима
    popup.html/js/css      вкладка, URL релея, режим, PIN, ссылка, счётчик зрителей

  server/
    relay.php              единый релей: start/frame/pull/stop/view/input/meta
    viewer.php             страница-зритель для гостя
    test-relay.mjs         интеграционный тест релея (нужен php)
  README.md
```

## Диагностика

- **«Не достучаться до релея»** — неверный URL, PHP-файл не загружен или сайт
  недоступен. Проверьте `relay.php?action=meta&session=x` в браузере.
- **«data dir not writable»** — папке рядом с `relay.php` не хватает прав на
  запись. Дайте права на создание подпапки `data`.
- **Пустой экран у гостя, но PIN принят** — вероятно, расшарена привилегированная
  вкладка (`about:*`): её нельзя снять. Переключитесь на обычную страницу.
- **Рвётся или тормозит** — снизьте FPS/качество; на слабом хостинге long-poll и
  частые кадры нагружают PHP. 
- **Клики «не проходят» на конкретном сайте** — сайт проверяет `isTrusted`;
  обойти это в рамках WebExtensions нельзя.
